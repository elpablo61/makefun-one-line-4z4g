One funny line for the [One Line, One Laugh](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) bounty on make.fun.

## The line

> The tooth fairy left Mia a note: 'Inflation. One tooth buys half a wish now.' She framed it.

92 characters. One concept (inflation), one named detail (Mia), one real turn, nothing explained.

## How it works

`main.ts` (Node 22) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(` /output/entry.txt` by default), with a built-in check that the line stays
inside the bounty gate of 1–140 characters and carries no trailing newline.

```sh
node main.ts
```
